CodeBench runs code that strangers write. These rules keep that safe and fair for everyone.

## Do

- Solve problems, experiment, and submit as many attempts as the rate limits allow.
- Write code that tries things — slow code, code that allocates, code that fails. That is what the budgets are for.
- Report anything that looks like a security problem to the project's GitHub repository. Describe it; don't
  exploit it.

## Don't

- Try to break out of the sandbox, reach the network from it, or affect the machines that run it.
- Try to extract hidden tests, reference solutions or other people's code — from the sandbox, the API or the app.
- Submit code designed to harm others, mine cryptocurrency, or waste resources on purpose (for example, spawning
  processes in a loop to exhaust limits).
- Script the API to scrape problems or to get around rate limits.
- Share your account or resell access.

## What happens if you do

Runs that break these rules are stopped by the sandbox's limits anyway. Accounts that keep trying can be
disabled without notice.
